# NBK Travels

NBK Travels is an Android application for booking and managing travel.

## Features

- User Authentication (Login/Register)
- Home screen with travel deals
- Booking management
- User settings and profile

## Project Structure

- `app/src/main/java/com/example/nbk_travels/data`: Data models and repositories.
- `app/src/main/java/com/example/nbk_travels/ui`: UI components, themes, and screens.
- `app/src/main/java/com/example/nbk_travels/util`: Utility classes.

## Getting Started

1. Clone the repository.
2. Open in Android Studio.
3. Build and run the app.
